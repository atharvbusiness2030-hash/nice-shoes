# NICE SHOES - Flagship Footwear Destination

A high-performance luxury footwear storefront featuring dual scroll-based 3D animations:
1. **Hero 360° Showcase**: 300-frame interactive scroll animation in a sticky viewport with sequential storytelling overlays.
2. **Slide 2+ Background 360° Animation**: 180-frame scroll-driven background animation that smoothly activates from Slide 2 (Trust strip & Categories) through the rest of the website.

## Tech Stack
- Pure HTML5 + Canvas + Modern JavaScript
- Tailwind CSS (Dark Luxury Theme)
- High-DPI Canvas Rendering with Momentum Lerp Interpolation
- Vercel-ready static configuration with immutable edge caching (`vercel.json`)

## Deploy on Vercel
1. Import this repository in [Vercel](https://vercel.com).
2. Framework Preset: **Other** (Static HTML).
3. Click **Deploy**.

## Local Development
Run with PowerShell:
```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```
Open `http://localhost:5000` in your browser.
